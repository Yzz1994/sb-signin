Cookie 获取指引
方式一（推荐）：浏览器扩展一键获取
  1. 解压 extension 目录（已随程序提供）
  2. 打开 chrome://extensions（Edge 为 edge://extensions），开启「开发者模式」
  3. 点「加载已解压的扩展程序」，选择 extension 文件夹
  4. 登录 sb.sb 后，点击工具栏上的扩展图标，会自动读取 Cookie 并回传到本服务

方式二：手动粘贴 Cookie
  1. 浏览器登录 sb.sb，按 F12 → 「应用/Application」→ Cookies → sb.sb
  2. 复制 __Host-bbs_session 和 __Host-bbs_csrf 两行的值，或直接复制整段 Cookie: name=value; ... 粘贴到添加账号弹窗里自动解析
